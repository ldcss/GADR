# GADR — Architecture Decision Records Generation

This repository contains the scripts and data used to generate Architecture Decision Records (ADRs) from meeting transcripts and to compare different generation strategies.

This artifact is self-contained and organized so that another researcher can understand the inputs, reproduce the runs, and inspect the generated outputs.

Access the accepted article here: [GADR_IIER_2026.pdf](https://github.com/user-attachments/files/30288552/GADR_IIER_2026.pdf)



## Project Structure

```text
├── adrs_json/         JSON files listing the ADR source repositories
├── chroma_db/         Local Chroma database built from the ADR dataset
├── dataset_adrs/      Consolidated ADR dataset used by the retrieval pipeline
├── downloaded_adrs/   ADRs downloaded from the source repositories
├── evaluation/        Evaluation results and comparison tables
├── generated/         ADRs generated by the three approaches
├── transcriptions/    Meeting transcripts used as input
├── constants.py       Transcript currently used by the scripts
├── few_shot_adr.py    Few-shot ADR generation script
├── zero_shot_adr.py   Zero-shot ADR generation script
├── research_agent_adr.py  Agentic RAG-based ADR generation script
├── requirements.txt   Python dependencies
└── LICENSE            Project license
```

## Requirements

- Python 3.10 or newer.
- macOS, Linux, or Windows with a working terminal.
- Internet access if you want to run the scripts that call external services.
- API keys or credentials for the external services used by the scripts, including Google Gemini (using Vertex AI API) and Tavily.
- Enough local disk space to store the dataset, Chroma database, and generated outputs.

The Python dependencies are listed in `requirements.txt`.

## Installation

1. Create and activate a virtual environment.

```bash
python3 -m venv venv
source venv/bin/activate
```

2. Install the dependencies.

```bash
pip install -r requirements.txt
```

3. Copy the example environment file and fill in your keys.

```bash
cp .env.example .env
```

4. Run one of the scripts.

```bash
python3 zero_shot_adr.py
```

A successful run should generate an ADR output without import errors or missing-key failures.

## How to Use

The scripts were created from notebook exports and rely on the transcript defined in `constants.py`.

- `few_shot_adr.py` runs a few-shot prompt-based approach.
- `zero_shot_adr.py` runs a zero-shot prompt-based approach.
- `research_agent_adr.py` runs the agentic pipeline with retrieval over `dataset_adrs/`.

You can replace the transcript in `constants.py` with another meeting transcript if needed.
